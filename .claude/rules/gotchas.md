# Gotchas

- **`npm run lint` enumerates src dirs explicitly** (see package.json) — a new top-level `src/` dir is silently unlinted until added to the script. Same for tsconfig `include`.
- **In-page debug handle**: `globalThis.storyOrchestratorRuntime` (RuntimeManager) — `importStory(json)`, `runExtractionNow(response?, reason?)`, `getSnapshot()`. Plan 08 adds: `runConsolidation()` (P4 dedup + supersession + bridge + WI sync), `runSupersessionBridge(entries)`, `syncWorldInfo()`, `getMemoryInjectionBlocks()`. Plan 09 adds: `getArcs()`, `getOpenArcs()`, `setArcPinned(id, bool)`, `removeArc(id)`, `runArcSummaryPass(arcIds)` (P4: resolved-arc summaries → canon regen), `getCanon()` (derived canon, falls back to canon-lite), `regenerateCanon(force?)`. Arc `[arc]`/`[resolved]` lines ride the same shared read as MEMORY/DELTA; a confirmed `[resolved]` matching an authored `arc_bridges` keyword enqueues a code-side `progress_toward_<anchor>` increment at the next boundary. Plan 10 adds: `getEpistemic()`, `getLedger()` (LedgerView[] incl. blackboard-mirrored bound rows), `getEpistemicBlock()`/`getLedgerBlock()` (macro/injection text), `runEpistemicLedgerPass(audit)` (P2 combined per-scene epistemic + ledger pass, `[retire]` supersession), `onMemberDrafted(chId)`/`clearPrivateInjection()` (private per-draft swap + restore), `setEpistemicLedgerCapable(bool)`, `setEpistemicPinned(id,bool)`/`removeEpistemicEntry(id)`/`setLedgerPinned(id,bool)`/`removeLedgerEntry(id)`. Epistemic `[knows]/[unaware]/[suspects]/[believes]/[hiding]` + ledger `[state:Entity:type] field=value` lines ride the same shared read as MEMORY/DELTA **only when the capability profile is on**; the full pass runs at scene breaks. A ledger field bound to a quality via `ledger_binding {entity, field}` is written **only** through the blackboard (single writer) and mirrored read-only into `getLedger()`; extracted `[state:…]` lines for a bound field are dropped. Plan 13 adds: `getPossibleTransitions()` (macro source), `getAwayRecap()`/`showAwayRecap()` (gap-reopen popup), `getPayloadCaptures()`/`capturePayload(reason?)` (last-5 injected-block ring, captured on `generation_started`, shown in the drawer Payload tab). Separate global `globalThis.storyOrchestratorLiveSuite.runFixture(spec)` powers `so-live-suite.mts` (real-model delta accuracy). Macros registered via `MacrosParser`: `story_title/description/current_checkpoint/past_checkpoints/possible_transitions/tension/player_name/role_<id>` + the earlier blackboard/canon/memory/epistemic/ledger ones. Slash: `/so-mem list|pin|exclude|backlog`. Epistemic is **never** written to World Info (privacy). Debug-response globals: `storyOrchestratorDebugExtractionResponse` (shared read), `storyOrchestratorDebugSceneSummaryResponse` (P2 scene-summary pass), `storyOrchestratorDebugShortTermResponse` (P2 short-term rolling compaction — `runShortTermCompaction()`/`shouldCompactShortTerm(lastMessageId)`, single rolling `short_term` entry every ~12 messages), `storyOrchestratorDebugSupersessionResponse` (plan 08 latching-bridge DELTA pass), `storyOrchestratorDebugArcSummaryResponse` (plan 09 arc-resolution summary), `storyOrchestratorDebugCanonResponse` (plan 09 canon synthesis), `storyOrchestratorDebugEpistemicResponse` + `storyOrchestratorDebugLedgerResponse` (plan 10 P2 pass). Used by gate check scripts and ad-hoc `browser_evaluate`.
- **Plan 14 speaker direction**: `globalThis.talkControlInterceptor` is now the LIVE enforcement point (set inside `startRuntime()`; never re-assign it after startup — `index.tsx` used to re-stub it post-start, which silently disabled the feature). - **Plan 08 embeddings use ST's vectors backend** (`/api/vector/{insert,query,purge}` via `stHost/vectors.ts`, `source: 'transformers'`, no config). Query returns threshold-filtered `metadata` (score dropped server-side at `src/endpoints/vectors.js:390`) — dedup bands are read via two threshold queries (dup 0.82 / same-topic 0.55), not raw scores. Jaccard (`similarity.ts`) is the fallback when no source. Consolidation runs P4 on a boundary cadence and only for tier groups ≥ `CONSOLIDATION_MIN_GROUP` (8).

- **A wizard journey writes to the real ST install.** `scripts/debug/so-assets.mts list|remove|assert-clean --marker <prefix>` is the only cleanup path, and it is scoped to the marker **plus** the names the wizard recorded in `wizardSessions[].applied` (a model that renames an asset would otherwise leak it). `cleanup.removeCreatedAssets` in a journey file runs inside the runner's `finally` and re-lists afterwards — a leftover asset fails the run.
- **`so-state` reads persisted `chat_metadata`** — live in-page values between persist cycles may differ.
- **ST `public/scripts/a11y.js` force-rewrites `role="button"` onto `.menu_button` elements** via a body-wide MutationObserver — our drawer tab buttons render with `role="tab"` in source/Storybook but show `role="button"` in the live DOM. Live selectors must use `#drawer-manager [role="tablist"] button` (what `so-ui.mts drawer-tab` does), never `[role="tab"]`. `aria-selected` survives the rewrite.
- **Settings panel root id is `#story-orchestrator-settings`** (renamed 2026-07-07 from legacy `#stepthink_settings`, which collided with the real Stepped Thinking extension's own root id) — debug selectors depend on it.
- **ST's `<html>` has `-webkit-transform: translateZ(0)`** (style.css Chrome-flicker fix) — it is the containing block for ALL `position:fixed` descendants; in ST mobile mode (`max-width:1000px`) `body{position:fixed}` collapses html's box to 0px height, so any fixed+`inset-0` overlay collapses with it. **Modal overlays must be native `<dialog>`+`showModal()`** (top layer, immune) — that's what `#so-studio-modal` is; ST's own popups do the same. Storybook plays that query dialog content must use retrying `find*` queries (mount effect opens the dialog after first render).
- **`ST_DEBUG_VIEWPORT=<W>x<H>`** (e.g. `390x844`) makes every debug script hold that emulated viewport (`lib/connection.mts`); without it, any script run resets viewports narrower than 1280px back to 1920×1080 — prefix EVERY command in a responsive test sequence.
- **Jest runs `--runInBand`**; tests colocated as `src/**/*.test.ts`, excluded from tsconfig/lint.
- **Host types are vendored locally** (`src/services/stHost/hostTypes.ts` — narrow interfaces + index signatures; base context from `globalThis.SillyTavern.getContext`) — typecheck/build/test work **outside the ST tree** too. Every vendored member has a host file:line row in 00-overview's "Verified ST host facts"; verify there before widening a type. Macros go through `registerHostMacro`/`unregisterHostMacro` (stHost/context.ts) — still MacrosParser underneath (sole dual-engine API while `experimental_macro_engine` is flag-gated; ST's [DEPRECATED] warns are expected transition noise); migrate the seam body when ST flips the flag default or removes MacrosParser. Event subscriptions use eventTypes constant KEYS (`"CHAT_CHANGED"`), resolved to values via `getContext().eventTypes[key]` in stHost/events.ts.
- **Extraction `stabilityLag` defaults to 0** (cadence reads include the newest message; swipes covered by rollback + P0 re-read). Existing chats keep their persisted value.
- **Tailwind 4** uses `@tailwindcss/postcss` plugin (not classic `tailwindcss` PostCSS plugin).
- **Webpack fallbacks** disable `fs`, `http`, `https`, `url`, `crypto` — no node builtins in browser target.
- **`dist/` is gitignored**; run `npm run build` before committing only if dist needs updating.
