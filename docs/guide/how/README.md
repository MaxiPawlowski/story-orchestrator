# How it works

These pages explain what the extension does behind each turn, one diagram per flow. They are written for curious
players and story authors who want to see the machine; you do not need them to play.

Each page names the source files and symbols it describes. A test fails when one of them disappears, so a diagram cannot
quietly drift away from the code.

1. [A turn, end to end](turn.md): from your message to the story moving on.
2. [Rollback](rollback.md): what a swipe, edit or delete undoes.
3. [Reading the story off the critical path](extraction.md): how the story learns what happened.
4. [Memory and held secrets](memory.md): what each character is allowed to know.
5. [Talk pacing](talk.md): who speaks next, and when the story hands the turn back to you.
6. [Lore](lore.md): story lorebooks, checkpoint gating and the lore curator.
7. [Images and the GPU](images.md): from a picture request to a picture in the chat.
8. [Models and routes](models.md): which model answers which job.
9. [The story wizard](wizard.md): from an idea to a saved story.
