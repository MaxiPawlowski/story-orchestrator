# Showcase

Live demos of what the extension looks like. Everything here runs on mock data or synthetic art made for this site;
nothing talks to a model or a server.

## UI components

Every panel, card and control of the extension has a story in the component browser: the kit, the Play page, the story
sheet, the HUD, the workspace, the Studio, the inline timeline and the in-chat elements. The theme toolbar switches
between SillyTavern's dark and light themes.
